# Blocky Bedrock Add-On (prototype)

This is a **separate Minecraft Bedrock Edition add-on**. It does not use Fabric, Java Edition mod loaders, or the Fabric JAR.

## Current prototype features

- Custom companion entity: `blocky:companion`.
- One slash command: `/aiplayerspawn`.
- Blocky follows the player who spawned it.
- Chat controls:
  - `Blocky, hello` / `Blocky, привіт`
  - `Blocky, follow` / `Blocky, йди за мною`
  - `Blocky, stop` / `Blocky, стій`
  - `Blocky, spawn` — spawn another companion if none exists.
- Basic humanoid presentation using the Bedrock humanoid geometry and the vanilla Steve texture.

## Install

1. Download the `.mcaddon` artifact from a successful **Build Bedrock Add-On** GitHub Actions run.
2. Open the downloaded `.mcaddon` on Android or Windows and choose Minecraft to import it.
3. In world settings, activate both **Blocky Companion - Behavior Pack** and **Blocky Companion - Resource Pack**.
4. Enable the **Beta APIs / Script API** experiment if your Bedrock version requires it for custom script commands or chat events.
5. Enter the world and run `/aiplayerspawn`.

## Important limitations

- This is an early Bedrock prototype, not a port of every Java/Fabric feature.
- It does not connect to Gemini, OpenRouter, DeepSeek, or OpenAI yet. Chat responses are local scripted phrases, not generated by a remote AI model.
- Chat event support and custom commands depend on the Script API version available in the installed Bedrock release. The chat listener is guarded so the pack can still load if that event is unavailable.
- The companion currently follows by periodic teleport when it gets too far away; this is a prototype behavior, not full pathfinding.
- PvP training, resource gathering, inventory management, crafting, and long-term AI memory are not implemented in this Bedrock prototype.
- The resource pack currently references the vanilla Steve texture and humanoid geometry supplied by the game.

## Development

The source is in `bedrock/BP` and `bedrock/RP`. GitHub Actions validates the JSON files and packages both packs into a single `.mcaddon`.
